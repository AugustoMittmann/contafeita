Painel do canal, ferramenta interna do canal Conta Feita · atualizada em 21/10/2026

O que é o Painel do canal

O Painel do canal é uma ferramenta de uso interno, que roda apenas no computador do responsável pelo canal do YouTube Conta Feita. Ela serve para enviar e agendar os vídeos e Shorts do próprio canal. Não é oferecida ao público e só é usada pela conta Google do próprio canal.

Quais dados acessamos

Com a autorização do dono da conta, pela tela oficial do Google (OAuth), o Painel usa os Serviços de API do YouTube para:

  • enviar vídeos e definir título, descrição, tags, categoria, idioma, data de publicação e miniatura (videos.insert, thumbnails.set);
  • adicionar vídeos a playlists do próprio canal (playlistItems.insert);
  • ler o nome e a imagem do canal conectado, para mostrar qual conta está conectada (channels.list).

O Painel não lê nem coleta dados de outros usuários, espectadores, comentários ou métricas de terceiros.

Como os dados são guardados

O token de acesso fornecido pelo Google fica salvo somente no computador do responsável pelo canal. Nenhum dado é enviado para servidores próprios, vendido ou compartilhado com terceiros. Os dados só vão para o próprio YouTube e Google, ao enviar e agendar os vídeos.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento nas configurações de segurança da conta Google: myaccount.google.com/permissions. Também é possível apagar o token salvo no computador.

YouTube e Google

O Painel usa os Serviços de API do YouTube. Ao usá-lo, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Privacy Policy

Painel do canal, internal tool of the Conta Feita YouTube channel · last updated October 21, 2026

What it is. Painel do canal is an internal tool that runs only on the computer of the owner of the Conta Feita YouTube channel, used to upload and schedule that channel's own videos and Shorts. It is not offered to the public and is used only by the channel's own Google account.

Data accessed. With the account owner's consent through Google OAuth, it uses the YouTube API Services to upload videos and set their metadata, publish date and thumbnail (videos.insert, thumbnails.set), add videos to the channel's own playlists (playlistItems.insert), and read the connected channel's name and picture (channels.list). It does not read or collect data from any other users or viewers.

Storage and sharing. The OAuth token is stored only on the channel owner's computer. No data is sent to our own servers, sold, or shared with third parties; data only goes to YouTube/Google to upload and schedule videos.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.

YouTube and Google. This tool uses the YouTube API Services. By using it, you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.
